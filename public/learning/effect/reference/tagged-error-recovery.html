Effect.catchTag

Effect v4 beta.103 · recover one expected error by its discriminator.

class StaticAssetFetchError extends Error {
  readonly _tag = "StaticAssetFetchError"
}

catchTag uses the readonly _tag field to select one recoverable error from the error channel.

program.pipe(
  Effect.catchTag("StaticAssetFetchError", (error) =>
    Effect.succeed(fallbackResponse)
  )
)
