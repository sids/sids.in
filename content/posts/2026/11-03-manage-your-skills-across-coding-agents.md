If you often switch between coding agents, or if you don’t do it because it is too tedious to set up (and keep in sync) skills, prompt templates etc, try using an agent skills management utility.

The most popular one is [`npx skills`](https://github.com/vercel-labs/skills) from Vercel and I use [`@sentry/dotagents`](https://github.com/getsentry/dotagents).
